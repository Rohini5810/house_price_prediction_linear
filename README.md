# 🏠 House Price Prediction Using Linear Regression

## 📌 About the Project
This project predicts house prices using Linear Regression, a Machine Learning algorithm.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Google Colab

## ⚙️ How It Works
- Load the dataset
- Train the Linear Regression model
- Predict house prices
- Evaluate model performance

## 🎯 Objective
To predict house prices using Machine Learning.

## 🌍 Applications
- Real Estate
- Property Price Estimation
- Housing Market Analysis
  
## 📌 Conclusion
This project uses Linear Regression to predict house prices based on housing data. It demonstrates the application
